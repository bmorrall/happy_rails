# Patterns

Ways to solve problems that come up when you follow the guide.

The guide sets the rules. These pages show how to work within them when a problem doesn't fit neatly, e.g. when a caller needs a value back from an action. They are suggestions, not rules. Pick the one that fits your problem. The agent instructions leave them out.
