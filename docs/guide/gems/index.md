# Gems

The gems I add to most apps, and how I use each one.
{: .fs-5 .fw-300 }

Every gem is optional. The rest of the guide doesn't depend on any of them. Each page shows how to use one gem within the guide's rules, if your app uses it.

Each gem has its own page here and its own instruction file. If your app does not use a gem, skip its page and delete its `happy_*.instructions.md` file.
