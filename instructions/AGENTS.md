# Agent instructions

This Rails app follows the Happy Rails conventions:
https://bmorrall.github.io/happy_rails/

Read and follow these files before you change code:

- `.github/instructions/happy_rails.instructions.md`: rules for every change.
- `.github/instructions/happy_*.instructions.md`: rules for one area of the app. The `applyTo` glob at the top of each file lists the paths it covers. Follow a file whenever you change a path that matches its glob.
- `.github/instructions/happy_setup_*.instructions.md`: steps to do once when you set up the app, e.g. base classes, initialisers and `spec/support` files. Follow one when you create or change a file its `applyTo` glob lists.
