# Agent instructions

This Rails app follows the Happy Rails conventions:
https://bmorrall.github.io/happy_rails/

Read and follow these files before you change code:

- `.github/copilot-instructions.md`: rules for every change.
- `.github/instructions/*.instructions.md`: rules for one area of the app. The `applyTo` glob at the top of each file lists the paths it covers. Follow a file whenever you change a path that matches its glob.
